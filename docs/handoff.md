# 交接记录：Gavin 版高保真数字花园

## 当前定位

站点面向希望了解 Gavin 技能、经历和项目的人，采用个人数字花园结构。参考了 Tania Rascia 网站的内容节奏与目录组织，但没有复制其源码、品牌、文案或素材。

页面顺序：

`侧栏 -> 个人时间线 -> 最新记录 -> 主题书架 -> 实践系列 -> 项目索引 -> 关于我 -> 联系`

## 代码边界

- `index.html` 保存当前公开页面结构与双语文案。
- `css/` 负责暖纸张背景、固定侧栏、时间线、索引行、书架卡片和项目网格。
- `js/main.js` 是唯一加载的入口，负责主题、语言、筛选和导航状态。
- `data/` 保留原始项目/辅导资料，后续整理内容时可作为事实来源；当前首页为了保持高保真索引布局，使用精选项目静态标记。
- `assets/lab-visual.svg` 已删除，首屏视觉使用原创 CSS 构图。

## 本地验证

```bash
python3 -m http.server 4173
```
